# themworkshop — sklep

Sklep noży kuchennych warsztatu [@themworkshop](https://www.instagram.com/themworkshop/) (Marek Kania) z panelem administratora.

**Live:** https://fauenem533.github.io/themworkshop/

## Uruchomienie

```bash
npm install
npm run dev
```

Lokalnie aplikacja jest pod `http://localhost:5173/themworkshop/` (base path jak na GitHub Pages).

## Panel admina

Adres: `/admin`  
Hasło demo: `themworkshop`

W panelu możesz:
- zmieniać ceny (także bezpośrednio w tabeli),
- dodawać / edytować / usuwać ogłoszenia,
- wybierać zdjęcia z Instagrama,
- wyróżniać produkty,
- resetować ofertę do domyślnej.

Dane zapisują się w `localStorage` przeglądarki.
